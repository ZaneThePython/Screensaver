# Screensaver

An ambient screen for Jibo, like a Chromecast's idle mode. Jibo dims his screen and shows either a slow slideshow of landscape and space photos with the time and date in a corner, or a whole game of Pac-Man that plays itself, with Jibo as Pac-Man. It can start by itself when Jibo has been idle for a while.

## How it works

1. Open **Screensaver** from Jibo's main menu to see its settings.
2. Under **Show**, pick **Photos** or **Pac-Man**.
3. Under **Start by itself**, pick how long Jibo must be idle first: 5 minutes, 30 minutes, 1 hour or 6 hours, or **Off**.
4. Tap **Start** to run it now. Jibo's screen dims to a soft night-light level while it runs.

**Photos:** a new photo fades in every 30 seconds, slowly zooming and drifting. The time and date move to the next corner at each change, visiting all four corners in turn, so nothing stays in one place long enough to burn in.

**Pac-Man:** Jibo's eye, turned into Pac-Man, plays a full game on its own: dots, power pellets, four ghosts that chase him the arcade way, lives, levels and game over, then a new game. Every level gets a new maze, and the board shifts a little each life so the walls never burn in.

## Controls

- **Tap anywhere**, or swipe down, to leave the screensaver. The screen goes back to its normal brightness.
- Swipe down on the settings screen to leave without starting.
- Say "Hey Jibo" at any time; he answers as usual.

## Requirements

5x1 3.1.7 or newer. Works offline; no account or internet connection needed. Asks for the **background** permission at install so it can start by itself; with **Off** picked it never does.
